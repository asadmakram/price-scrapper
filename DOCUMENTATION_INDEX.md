## 🎯 Quick Reference

### To start the app:
```bash
npm run dev
```

### To build for production:
```bash
npm run build
npm start
```

### To deploy:
```bash
vercel deploy
```

### To test APIs:
```bash
curl "http://localhost:3000/api/products?source=all&q=pepsi"
```

### To clear cache:
```bash
rm -rf .next node_modules && npm install
```
